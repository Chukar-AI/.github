**Chukar AI** builds open-source, zero-cloud AI systems and evaluation infrastructure focused on making frontier open-weight models fast, verifiable, and runnable on real hardware—from phones and consumer GPUs to multi-chip TPUs.

- **Vibe Assembly** — Pure-Rust multi-agent coding workspace with hash-anchored patches, `.ai/` contracts, and deterministic verification gates.
- **Vibe Router** — Single-binary Rust LLM gateway (OpenAI & Anthropic `/v1/messages`) with failover combos, key rotation, and MCP support.
- **Vibe Local & Vibe Grid** — Zero-cloud local inference manager, Android Pocket Worker, and distributed Wi-Fi MoE sharding.
- **Vibe Radar** — Automated discovery and live verification of free-tier LLM endpoints feeding Vibe Router.
- **GGUF → JAX (TPU)** — Memory-bounded, parity-verified open-weight model conversions for multi-chip TPU execution.
- **Vibe Bench** *(coming soon)* — Deterministic, anti-cheat quantization collapse leaderboard.
